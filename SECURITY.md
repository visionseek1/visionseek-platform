# Security Policy

VisionSeek takes responsible security research seriously.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to
`abdelalim@visionseek.org`. Do not open a public GitHub issue for a security
report.

Include the affected URL or component, reproduction steps, the potential
impact, and any supporting evidence. We will acknowledge a valid report as
soon as practical and coordinate remediation and disclosure with the reporter.

## Scope

The website, its deployment configuration, and first-party VisionSeek web
properties are in scope. Third-party services are governed by their own
security policies.

## Safe harbor

Good-faith research that avoids privacy violations, service disruption, data
destruction, and social engineering will be treated as authorized security
research to the extent permitted by applicable law.
