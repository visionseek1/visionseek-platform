# أخبار VisionSeek

كل خبر ملف واحد. إضافة خبر = إضافة ملفين في هذا المجلد (markdown + صورة البطل)، بلا تعديل كود أو JSON. نسخة og 1200×630 تُسمّى تلقائيًا `<الاسم>.og.<امتداد>` بجانب الأصل.

## الملفات

```
content/news/<slug>.md
content/news/<slug>.png
content/news/<slug>.og.png    # 1200×630 — إن غابت تُستخدم صورة البطل
```

نفس الـ slug في اسم الملف وفي الحقل `slug` وفي `heroImage`. الامتداد المسموح: `.jpg` / `.jpeg` / `.png` / `.webp` / `.avif` / `.svg`.

- البطل: أفقي 16:9 (1600×900). أعلى صفحة التفصيل وأعلى كل بطاقة.
- og: 1200×630 من نفس الرسم، مقصوصة. تُستخدم في `og:image` و`twitter:image`.

لا تضع الصورة في مجلد فرعي. ضعها بجانب ملف `.md`.

ملفات JSON القديمة في هذا المجلد تبقى مقالات القسم السابق (`/admin`). محرّك الأخبار يقرأ `*.md` فقط ويتجاهل `README.md`.

## الحقول (frontmatter)

```yaml
---
slug: 2026-10-27-example
title: العنوان بالعربية
dek: جملة واحدة ترد على «وده يفرق معانا في إيه؟»
publishedAt: 2026-10-27T09:00:00+04:00
updatedAt: 2026-10-27T12:00:00+04:00   # اختياري
tag: صحة
sourceName: اسم المصدر
sourceUrl: https://example.com
heroImage: 2026-10-27-example.png
heroAlt: وصف عربي للصورة
imageCredit: رسم توضيحي: VisionSeek (مولَّد)
readingMinutes: 1
corrections:                          # اختياري
  - at: 2026-10-27T12:00:00+04:00
    text: تصحيح [التاريخ]: …
sample: false
coverageName: تغطية إضافية            # اختياري
coverageUrl: https://example.com
titleEn: Optional English headline
dekEn: Optional English dek
---
```

| الحقل | إلزامي | ملاحظات |
|---|---|---|
| `slug` | نعم | أحرف إنجليزية صغيرة وأرقام وشرطات |
| `title` | نعم | العنوان العربي |
| `dek` | نعم | سطر واحد (كان `summary`) |
| `publishedAt` | نعم | ISO مع إزاحة. يُعرض بتوقيت الخليج (`Asia/Dubai`، GMT+4) |
| `updatedAt` | لا | إن وُجد يظهر «حُدّث» + الوقت |
| `tag` | نعم | ملف ثابت: تنظيم وسياسات · بنية تحتية وبيانات · صحة · تعليم وقدرات · استثمار وشركات · أمن |
| `sourceName` | نعم | اسم المصدر الظاهر |
| `sourceUrl` | نعم | رابط المصدر الأصلي |
| `heroImage` | نعم | اسم الملف بجانب الـ markdown (كان `image`) |
| `heroAlt` | نعم | نص بديل عربي (كان `imageAlt`) |
| `imageCredit` | نعم | يظهر تحت الصورة، مثل «رسم توضيحي: VisionSeek (مولَّد)» |
| `readingMinutes` | نعم | عدد صحيح موجب |
| `corrections` | لا | قائمة `{at, text}` |
| `sample` | لا | `true` = عيّنة تجريبية. لا تُنشر على الإنتاج |

البناء يرفض أي ملف ناقص الحقول الإلزامية أو بلا صورة بطل (إلا عيّنة بلا ملف: تظهر لوحة VisionSeek الاحتياطية).

## متن الخبر

```markdown
[فقرة افتتاحية — جملتان: مين/إيه/إمتى/فين + المصدر بالاسم]

## ما الذي حدث
- … (3–5 نقاط)

## لماذا يهم الخليج والعالم العربي

فقرة.

## قراءة VisionSeek

سطران. يُعرضان في صندوق بلون مختلف ووسم «رأي».

## ما الذي نراقبه

سطر واحد (اختياري).
```

## العيّنات والإنتاج

الملفات ذات `sample: true` تظهر فقط عندما `VERCEL_ENV === 'preview'` أو `NODE_ENV === 'development'`.

على الإنتاج (`VERCEL_ENV === 'production'`، وأي بناء بلا `VERCEL_ENV` مثل CI) تُحذف العيّنات من الفهرس والتفصيل وخريطة الموقع. دمج الفرع لا ينشر عيّنات.

إذا لم يبقَ في الإنتاج أي خبر غير عيّنة، يُخفى بند «أخبار» من القائمة العلوية والتذييل.

العيّنات الحالية معلّمة: العنوان يبدأ بـ «خبر تجريبي:»، المصدر `https://example.com`، ووسم «عيّنة تجريبية»، وصور تجريدية مولَّدة.

## المسارات

- `/ar/news` — فهرس: كارت كبير ثم شبكة عمودين، فلتر ملفات، «المزيد»
- `/ar/news/<slug>` — التفصيل
- `/news` و`/news/<slug>` — الإنجليزية إن وُجدت `titleEn` و`dekEn`
