# غرفة القدرات الخاصة بالمؤسس

**26 سبتمبر 2026 · شرط صريح من المؤسس · تصميم مطلوب، لم يُنفذ أو يُختبر بعد.**

## النطاق

جميع القدرات الأربع عشرة، والأدوات المرتبطة بها، والبيانات والمستندات والبحث والتجارب والقرارات والنتائج، تعيش داخل غرفة خاصة بالدكتور أحمد. المستخدم البشري الوحيد في النطاق الحالي هو المؤسس. لا يمنح التسجيل في الموقع أو دور محرر بيت القادة أو عضوية مؤسسة أخرى حق دخول الغرفة.

هذا التوجيه يحل محل اقتراحات إظهار الغرفة في القائمة العامة، وقراءة بياناتها للزوار، وربط المنشورات العامة مباشرة بنتائجها. تبقى المجالات الثمانية والقدرات المشتركة أسلوب تنظيم داخلي. لا نفتح مساحات عمل للعملاء أو الفريق ضمن هذا النطاق.

## الدخول والوصول

| السطح | السلوك المطلوب |
|---|---|
| التنقل | مدخل «غرفة القدرات» داخل لوحة المؤسس بعد دخوله. لا رابط لها في القائمة العامة أو خريطة الموقع أو البحث العام |
| صفحات الغرفة | تحقق على الخادم قبل إعادة أي بيانات أو تحميل ملفات. يمكن الاحتفاظ بمساري `/capabilities` و`/ar/capabilities` المحميين؛ معرفة الرابط لا تمنح الوصول |
| الهوية | مطابقة معرّف المستخدم الثابت في Supabase مع إعداد المؤسس الموثوق على الخادم. الرفض هو الافتراضي؛ لا نعتمد على بريد يرسله العميل أو علم واجهة قابل للتعديل |
| قاعدة البيانات | سياسات RLS وقيود وصول تغطي كل جدول وعرض ودالة مستخدمة. سجلات الغرفة مرتبطة بمالكها، والخادم يحدد المالك من الهوية الموثقة |
| الملفات | تخزين خاص، وصول مصادق عليه أو روابط قصيرة العمر تصدر بعد تحقق الملكية. لا حاويات عامة أو روابط دائمة للنتائج |
| API وMCP | نفس قواعد هوية المؤسس والتفويض على القراءة والتنفيذ والنتائج. بيانات الغرفة وأسماء أدواتها ومواردها لا تُتاح لعميل غير مخول؛ بيانات اكتشاف التفويض القياسية لا تحمل محتوى الغرفة |
| المهام الخلفية | حسابات خدمات محددة المهمة، مرتبطة بالمؤسس وبنطاق المصدر أو التجربة. مفاتيح الخدمات تبقى على الخادم؛ استخدام صلاحية تتجاوز RLS يفرض تحققًا مستقلًا من النطاق |
| الذاكرة المؤقتة والتسجيل | منع تخزين الردود الخاصة في cache مشترك أو تسريبها عبر التحليلات ومعاينات الروابط والأخطاء. السجلات تحفظ أقل بيانات لازمة ولا تسجل أسرارًا أو مستندات كاملة |

إخفاء الرابط و`noindex` إجراءات إضافية؛ الحماية تعتمد على تحقق الخادم وسياسات البيانات والتخزين. endpoint بعيد يمكن أن يكون قابلًا للوصول عبر الإنترنت حتى يتصل به عميل MCP، مع بقاء استخدامه ومحتواه مقصورين على التفويض الصحيح.

## المساعدون والبيانات الخارجية

- ChatGPT وClaude وGrok أو أي عميل متوافق يدخل بتفويض يمنحه المؤسس لعميل محدد، بنطاق قراءة أو تنفيذ قابل للإلغاء. وجود اشتراك لا ينشئ تفويضًا.
- يحصل الوكيل على البيانات اللازمة للمهمة فقط. لا تمنحه نصوص المستندات أو مخرجات الأدوات صلاحيات إضافية، ولا يعتمد طلبه بنفسه إذا كان يحتاج قرار المؤسس.
- تظل الغرفة خاصة بالوصول البشري، لكن استخدام نموذج أو خدمة خارجية قد يرسل إليها بيانات المهمة. يوثق كل موصل وجهته ونطاق البيانات وإعدادات الاحتفاظ والمعالجة قبل تفعيله؛ لا نفترض أن الخصوصية تعني تشغيلًا محليًا كاملًا.
- جلب مصادر عامة لا يجعل سجل المؤسس أو ملاحظاته أو تحليلاته عامة. تبقى الاستعلامات والمفضلات والنتائج والمخرجات المشتقة ضمن الغرفة.

## العلاقة بالموقع وبيت القادة

تظل غرفة القدرات مساحة العمل الخاصة. توليد مادة قابلة للنشر ينتج مسودة خاصة يراجعها المؤسس. نشر مادة في بيت القادة يحتاج اختيار محتوى محدد واعتماده صراحة؛ لا مزامنة تلقائية ولا نشر للغرفة أو مرفقاتها.

أي مادة يختار المؤسس نشرها لاحقًا تُنسخ إلى سجل النشر المستقل بعد المراجعة، بروابط مصادر عامة مسموحة. لا تحمل رابط نتيجة خاصة أو رمز دخول أو ملفًا أصليًا خاصًا. هذا مسار اختياري لاحق؛ قبول M5 الحالي هو تجهيز المسودات الخاصة، وليس نشرها.

## اختبارات لازمة لقبول M0

1. يستطيع المؤسس الدخول وقراءة أول بيانات فعلية من الواجهة ومن عميل MCP مخول.
2. يُرفض الزائر غير المسجل والمستخدم المسجل غير المؤسس، بما في ذلك محرر محتوى عام، عند فتح رابط الغرفة أو استدعاء API/MCP مباشرة.
3. لا تتيح معرفة معرّف سجل أو ملف أو تشغيل الوصول إليه؛ يفشل الوصول المباشر عبر واجهات قاعدة البيانات والتخزين دون التفويض الصحيح.
4. تفويض MCP للقراءة لا يسمح بالتنفيذ؛ إلغاء التفويض يمنع الطلب التالي. المهام المتأثرة بالإلغاء تُوقف أو تُمنع من بدء أثر جديد بحسب حالتها وصلاحياتها المسجلة.
5. لا تظهر بيانات الغرفة في HTML عام أو sitemap أو نتائج البحث العام أو cache مشترك أو صفحة خطأ أو مخرجات تحليل الزيارات.
6. لا يؤدي إكمال مهمة أو توليد مسودة إلى نشر محتوى أو ملف في بيت القادة. خدمات الخلفية تحفظ النتائج في نطاق المؤسس وتتحقق من صلاحية المهمة.

هذه بوابة تحقق عند التنفيذ. لم تُنشأ سياسات أو مسارات أو اتصالات جديدة في خطوة التصميم الحالية.
